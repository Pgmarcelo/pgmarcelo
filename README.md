## Selected work

### [AI Capacity Conversion Canvas](https://github.com/Pgmarcelo/ai-capacity-conversion-canvas)

A vendor-neutral framework for deciding where recovered employee capacity should go after an AI implementation. It includes a workflow canvas, measurement plan, controls, a fictional worked example and a spreadsheet-ready template.

### [Multi-Agent Vacation Recommendation Demo](https://github.com/Pgmarcelo/vacation-recommendation-demo)

A hands-on demonstration of multiple AI agents collaborating through MCP and A2A, with an orchestrator prepared for deployment using Amazon Bedrock AgentCore. It is a technical learning project, not a production service.

### [Which CDN](https://github.com/Pgmarcelo/whichcdn_2024)

A small Python and Flask application that uses DNS, IP ownership and HTTPS response signals to identify possible infrastructure-provider fingerprints. Results are heuristic and intended for local analysis.
